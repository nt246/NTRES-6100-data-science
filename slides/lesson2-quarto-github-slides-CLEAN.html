What is Quarto?

A plain-text document that lets us write code and text together.

When we render the document:

  • Markdown is formatted
  • code is executed
  • results are inserted
  • a human-readable document is created
One source file can contain the analysis and the report.

Why do this?

analysis → save plot → paste into Word → change analysis → re-save plot → re-paste plot → realize a number in paragraph 3 is now wrong…
With Quarto:
Change the analysis → render again → document updates

What happens behind the scenes?

.qmd source→execute code→render→HTML / PDF / Word / GFM

For R, Quarto uses knitr to execute code and Pandoc to create the final document.

Quarto and R Markdown

What carries over?

Markdown, R code, knitr, figures, narrative text, reproducible documents.

Why Quarto?

A newer, more consistent publishing system with strong support for multiple languages, cross-references, websites, presentations, and more.

If you know R Markdown, you do not need to relearn everything.

Executable code cells

A basic R code cell: 

```{r}
summary(cars)
```
  • the backticks mark the cell boundaries
  • {r} tells Quarto the code is R
Code + output + explanation can stay together.

Cell options

Put options on #| lines at the top of a code cell: 

```{r}
#| echo: false

plot(pressure)
```

The code runs, but the code itself is not shown.

Activity: Compare echo and eval

Try this in your document:

  1. add #| echo: false to a code cell and render
  2. change it to #| eval: false
  3. render again

What is the difference?

Focus on what gets executed and what the reader sees.

Figures, labels, captions, references

```{r}
#| label: fig-pressure
#| fig-cap: "Relationship between temperature and pressure."

plot(pressure)
```

Then refer to it with: 

See @fig-pressure.
Quarto handles numbering and cross-references automatically.

Inline R code

Instead of manually typing a value: 

The cars dataset contains `{r} nrow(cars)` observations.

Quarto calculates it when the document renders.

If a value can be generated from the data, let the computer generate it.

Rendering is a reproducibility check

Interactive code may work because your current R session contains things the document does not.

Rendering can expose:

  • objects created earlier but missing from the document
  • packages you forgot to load
  • fragile file paths
  • code run in the wrong order
A successful render is one useful test of whether your analysis is reproducible.

Git and GitHub are not the same thing

Git

Version-control software on your computer. Tracks changes to files over time.

GitHub

An online service that stores Git repositories and supports collaboration.

Why version control?

Git lets us:

  • see what changed
  • see when it changed
  • see who changed it
  • return to an earlier version
  • collaborate without files named analysis_final_FINAL_v2.R
Today: configuration only. Next class: the actual Git workflow.

Two things to configure

Git identity

Who are you? Git records your name and email with commits.

Usually once per computer.

GitHub authentication

Store a personal access token (PAT) so RStudio can authenticate with GitHub.

PATs expire and must be renewed.

Install and load usethis

Install once: 

install.packages("usethis")

Load in the current R session: 

library(usethis)
No Console feedback after library(usethis)? Unless you got an error, it worked.

Activity: Configure your Git identity

use_git_config(
  user.name = "Your Name",
  user.email = "you@example.com"
)

Use the email associated with your GitHub account.

Do this now.

GitHub authentication

GitHub does not accept your normal GitHub account password for Git operations over HTTPS.

Instead, we use a personal access token (PAT). 

usethis::create_github_token()
  • give it a descriptive name
  • choose an expiration
  • leave the pre-selected scopes
  • copy it immediately
GitHub will only show you the complete token once.

Activity: Store your PAT

Install gitcreds if needed: 

install.packages("gitcreds")

Then run: 

gitcreds::gitcreds_set()

Paste the PAT when prompted.

Nothing may appear when you paste — that is normal.

For path issues, compare Terminal:
